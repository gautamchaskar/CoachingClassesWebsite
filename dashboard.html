Module 3: LWC Architecture Recorded Aug 18, 2026 • 1h 45m • Instructor: Gautam Chaskar

Lecture 3.2: @wire Service & Imperative Apex Calls in LWC

Comprehensive deep-dive into Reactive Wire Service adapters, wire to property vs wire to function, imperative Apex method invocation, and handling error toasts gracefully in Lightning Web Components.

Key Concepts & Takeaways

  • @wire Service: Reactive data provisioning from Salesforce Data Cloud / Apex controllers. Automatically updates DOM when data changes.
  • Cacheable=true: Mandatory on Apex method signatures when invoking via `@wire`.
  • Imperative Apex: Used for DML operations (Insert, Update, Delete) or when user action (button click) triggers execution.
  • Toast Notifications: Import `ShowToastEvent` from `lightning/platformShowToastEvent` to display error/success toasts.

LWC Controller JavaScript Code Snippet

import { LightningElement, wire, api } from 'lwc';
import getAccountList from '@salesforce/apex/AccountController.getAccountList';

export default class AccountViewer extends LightningElement {
    @api recordId;
    accounts;
    error;

    // Reactive Wire Service Adapter
    @wire(getAccountList)
    wiredAccounts({ error, data }) {
        if (data) {
            this.accounts = data;
            this.error = undefined;
        } else if (error) {
            this.error = error;
            this.accounts = undefined;
        }
    }
}
