Salesforce Full Stack Curriculum

Curated by Gautam Chaskar (7x Salesforce Certified) to take you from absolute beginner to Job-Ready Senior Developer.

01
Salesforce Admin & Platform Fundamentals
Module 1 • Weeks 1 to 4
  • Cloud Computing Concepts, Multi-Tenant Architecture & Org Setup
  • Standard & Custom Data Objects, Fields, Formulas & Validation Rules
  • Data Security Model: Profiles, Roles, OWD, Sharing Rules & Permission Sets
  • Automation Tools: Salesforce Flow Builder, Approval Processes & Record-Triggered Flows
  • Reports, Dashboards, Data Loader & Mass Data Import/Export
02
Apex Programming & Database Queries (SOQL/SOSL)
Module 2 • Weeks 5 to 8
  • Apex Language Fundamentals, OOPs Principles, Collections (Lists, Sets, Maps)
  • Apex Triggers & Trigger Framework Architecture (before/after events, context variables)
  • Governor Limits Optimization, SOQL & SOSL Queries with Dynamic Apex
  • Asynchronous Apex: Batch Apex, Queueable Apex, Scheduled Apex & Future Methods
  • Apex Unit Testing Framework & Achieving 90%+ Code Coverage
03
Lightning Web Components (LWC) & Modern JS
Module 3 • Weeks 9 to 12
  • Modern JavaScript (ES6+ Arrow Functions, Promises, Async/Await, Destructuring)
  • LWC Component Architecture, Shadow DOM & Component Lifecycle Hooks
  • Data Binding, Reactive Properties (@api, @track, @wire service)
  • Component Communication (Custom Events, Lightning Message Service LMS)
  • Calling Imperative Apex from LWC & Handling Server Response
04
Salesforce Integration Architecture & APIs
Module 4 • Weeks 13 to 14
  • REST & SOAP Web Services Architecture in Salesforce
  • Exposing Custom REST APIs in Apex (@RestResource, @HttpGet, @HttpPost)
  • Outbound HTTP Callouts to External Payment & Weather APIs
  • OAuth 2.0 Authentication Flows & Connected App Configuration

Live Capstone Projects & Placement Mentorship
